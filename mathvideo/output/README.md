## 作り方（再生成）

`mathvideo/` 内のPythonスクリプトで生成しています。

- `content/chNN.py` … 台本（画面の構成・ナレーション・効果音の指定）。数式はLaTeX（KaTeXで描画）
- `verify.py` … 台本中の数式を sympy で機械検証（途中式の同値・たすき掛けの計算・循環小数の分数化など）
- `build.py` … 画面描画（Chromium）→ 音声合成（edge-tts）→ 効果音・BGM合成 → ffmpegでmp4化
- `sfx.py` / `bgm.py` … 効果音とBGMをコードで合成（外部素材なし）
- `assemble.py` … 通し動画とこのREADMEの作成
